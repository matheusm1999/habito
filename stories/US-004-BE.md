Como usuário, eu quero marcar um hábito como concluído no dia
para que eu possa acompanhar meu progresso diário.

Descrição:
Registrar e manter histórico de conclusões por data para cada hábito do usuário.

Critérios de aceite (Back-end):
- É possível registrar uma conclusão para um hábito em uma data específica.
- É possível remover/desfazer uma conclusão.
- Histórico por data é retornado corretamente nas consultas.
- Respostas informam sucesso/erro para o front-end.

Contexto:
Responsável por persistir o histórico de conclusão dos hábitos.
