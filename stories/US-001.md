# US-001 — Registrar hábito

Como usuário, eu quero registrar um novo hábito
para que eu possa acompanhar e iniciar uma rotina de ações diárias.

Critérios de aceite:
- Existe um formulário que permite inserir o nome do hábito.
- É possível adicionar uma descrição opcional.
- É possível definir a frequência (ex.: diário, dias da semana) e uma meta simples (ex.: 1 vez por dia).
- O hábito aparece na lista de hábitos após a criação.
- O sistema valida que o nome do hábito não esteja vazio.

Observações:
- Exemplo: "Beber água", frequência: diário, meta: 8x/dia
